Cantus

A lightweight desktop coding environment where Claude is a first-class citizen — not a bolted-on sidebar.

Download for macOS View on GitHub

macOS (Apple Silicon) · a single ~10 MB signed binary · local-first & private

One app, in concert

Editor, terminal, git, and a context-aware agent sharing one UI and one state.

🧠

Context-aware agent

Claude sees the open file, your selection, and recent edits — no copy-paste.

✍️

Edits as diffs

The agent proposes changes inline in Monaco; you accept or reject.

🖥️

Real terminal

A true shell via a backend-spawned PTY, themed to match.

🌿

Built-in git

Status, stage, commit, and an inline diff — via libgit2, no shelling out.

💾

Resumable sessions

Chat and agent history persist locally; resume with a summary re-seed.

🔒

Local-first & private

Your source never leaves the machine except the agent's own model calls.

Composed, not reinvented

Cantus wraps mature, battle-tested components — and builds only the glue and the genuinely novel parts.

Tauri 2 Rust React + TypeScript Monaco xterm.js libgit2 SQLite Claude Agent SDK
